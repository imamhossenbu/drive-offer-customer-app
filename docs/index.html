গ্রাহক অ্যাপ

ভার্সন ১.১.০ · ২০ MB · Android

⬇️ অ্যাপ ডাউনলোড করুন পুরোনো ফোনে ইনস্টল না হলে এটি নিন

কীভাবে ইনস্টল করবেন

  1. ডাউনলোড বাটনে চাপুনফোনে APK ফাইলটি নামা শুরু হবে।
  2. "Download anyway" চাপুনপ্লে-স্টোরের বাইরের যেকোনো অ্যাপের জন্য Chrome এই সতর্কবার্তা দেখায়। এটি স্বাভাবিক।
  3. ফাইল খুলে Install করুন"Unknown sources" অনুমতি চাইলে Allow দিয়ে ইনস্টল শেষ করুন।
  4. লগইন করুনমোবাইল নম্বর দিয়ে অ্যাকাউন্ট খুলুন বা লগইন করুন। নতুন আপডেট এলে অ্যাপ নিজেই জানাবে।
